# 🏦 Bank Management System

A beginner-friendly Bank Management System built using **Python** and **Streamlit**. It provides a simple web interface to manage bank accounts and perform basic banking operations.

## ✨ Features

- Create a new bank account
- Generate a unique account number
- Deposit money into an account
- Withdraw money with a balance check
- View account details after PIN verification
- Update name, mobile number, and email
- Delete an account after account number and PIN verification
- Store account records in a JSON file

## 🛠️ Technologies Used

- Python
- Streamlit
- JSON
